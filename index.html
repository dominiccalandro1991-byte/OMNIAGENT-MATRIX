OmniAgent Matrix

Signed telemetry. Capability-bounded tools.

Independent AI workforce control plane. Ingress verifies Ed25519 over the original raw bytes, then replay, schema, and authorization. Usage is provider-reported and server-authoritative. If Ed25519 is unavailable the service fails closed.

Pipeline

AGENT → EVENT → RAW SIGNATURE → REPLAY → PARSE → SCHEMA → AUTHZ → ROUTER → RUNTIME / TOOL / LLM → USAGE → BILLING → AUDIT
